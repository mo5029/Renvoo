# Backfill Under Clinic Control

## Snapshot

Renvoo should help fill empty slots, but the MVP should remain operationally cautious. Suggest, alert, and coordinate first; fully autonomous schedule mutation can come later if trust and integration depth justify it.

## Evidence

- `4.Replace` explicitly says MVP can keep actual schedule changes under clinic or EHR control.
- The founder summary treats backfill as strategically important but not necessarily fully implemented yet.

## Claims

- Backfill is part of the value proposition, but the MVP should avoid over-automating schedule control too early. (high) — 4.Replace, founder summary
