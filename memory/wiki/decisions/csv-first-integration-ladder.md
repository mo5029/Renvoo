# CSV First Integration Ladder

## Snapshot

Renvoo should default to the lightest viable integration path first. The current plan is exports and lightweight connectors now, real scheduling sync later.

## Evidence

- `1.Connect` outlines a CSV-watch workflow.
- `Pitch deck 2` and the founder summary both explicitly say CSV first.
- This approach reduces onboarding risk while pilots are still unproven.

## Claims

- Validation speed matters more than elegant deep integration at the current stage. (high) — Founder summary, 1.Connect, Plan for the short-term
