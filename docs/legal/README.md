# Renvoo Legal Pack

This folder contains a simple legal and compliance starter pack for Renvoo's Dutch clinic-SaaS pilot motion.

## Intended use

- Product shape: B2B clinic SaaS for Dutch private clinics, starting with dental clinics
- Operating model: clinic as controller for patient and appointment data, Renvoo as processor
- Product boundary: non-clinical, admin-data-only, no patient accounts in v1

## Review status

These templates are operational drafts, not signed legal advice. Review them with Dutch counsel before launch or signature.

## Folder map

- `corporate/`: BV setup and IP ownership documents
- `contracts/`: clinic-facing pilot agreement stack
- `privacy/`: notices, operational matrices, and GDPR process docs
- `regulatory/`: intended-purpose and boundary memo

## Suggested order

1. Finalize the intended-purpose memo in `regulatory/`.
2. Form `Renvoo B.V.` and complete the `corporate/` checklist.
3. Lock the data inventory, retention matrix, processor register, and DPIA-lite in `privacy/`.
4. Use the `contracts/` templates to prepare the first clinic pilot pack.
5. Publish and review the website and patient notices before live pilot traffic starts.
