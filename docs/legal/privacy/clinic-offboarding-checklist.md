# Clinic Offboarding Checklist

Run this at the end of each pilot unless the contract is being extended.

## Before offboarding

- confirm termination or completion date
- confirm clinic contact for export and deletion notice
- confirm whether any legal hold applies

## Export

- produce agreed export format
- confirm export contents match allowed pilot scope
- deliver export securely
- log delivery date and recipient

## Deletion

- disable clinic user access
- delete active pilot data after export confirmation
- close or anonymize support records where appropriate
- confirm backup aging window from the retention matrix

## Evidence

- record export completion
- record deletion completion
- record backup expiry date
- store offboarding note with contract documents
