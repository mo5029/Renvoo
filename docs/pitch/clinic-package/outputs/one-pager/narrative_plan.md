# Renvoo One-Pager Narrative Plan

- Audience: dental clinic owners and practice managers
- Objective: compress the same clinic narrative from the deck into a one-page leave-behind
- Structure:
  - top: headline, one-sentence description, scheduling visual
  - middle: problem and solution blocks
  - bottom: pricing, founder credibility, and CTA
- Visual system: same brand colors, same typography hierarchy, same card shapes, same scheduling motif as the deck
