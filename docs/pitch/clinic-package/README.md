# Renvoo Clinic Pitch Package

This package contains the clinic-facing Renvoo materials for dental outreach.

## Deliverables

- `master-copy.md`: locked source-of-truth wording for the deck and one-pager
- `talking-points.md`: internal speaking brief and objection handling
- `outputs/clinic-deck/renvoo-clinic-deck.pptx`: clinic pitch deck
- `outputs/one-pager/renvoo-clinic-one-pager.pptx`: one-page leave-behind

## Design Rules

- English-first
- Dental-first
- `70%` problem, `20%` solution, `10%` cost
- Same theme, same copy spine, same CTA across deck and one-pager
- Pricing is presented as preliminary pilot pricing only
