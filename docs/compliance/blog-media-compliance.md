# Renvoo Blog Media And Tone Compliance

This policy is a hard constraint for all blog media, visuals, examples, and supporting content in this repository.

If any output violates these rules, it must be rejected or regenerated.

## Visual And Media Restrictions

### 1. No images of women

Do not generate, embed, or suggest images containing women.

Do not use:

- stock photos featuring women
- people-focused imagery that includes women
- ambiguous lifestyle imagery

If an image is required, prefer:

- software UI
- dashboards
- product visuals
- abstract graphics
- icons
- charts
- neutral clinic interiors without identifiable people

### 2. No sexualized or suggestive content

Do not include:

- sexual references
- dating references
- relationship framing
- suggestive language
- adult themes

### 3. No 18+ content

Do not include or promote:

- adult industries
- mature themes
- explicit topics

### 4. No alcohol or drinking culture

Do not include:

- alcohol references
- bar or nightlife references
- drinking culture language
- analogies based on alcohol

If a neutral beverage must appear, keep it minimal and ordinary.

## Tone Restrictions

### 5. Professional tone only

Keep all content:

- professional
- respectful
- neutral
- business-appropriate

Do not use nightlife slang, adult-culture jokes, or edgy humor.

### 6. Business-appropriate examples only

Use examples related to:

- clinics
- healthcare operations
- scheduling
- admin workflows
- general business operations

Avoid unrelated lifestyle examples that could introduce risky or questionable elements.

## Final Validation

Before saving or publishing any blog:

1. Does this include any image or reference to women? If yes, reject.
2. Does this include any 18+ topic? If yes, reject.
3. Does this include alcohol or drinking references? If yes, reject.
4. Is all content strictly professional and neutral? If no, fix it.
